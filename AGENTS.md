# Coding agent instructions
- Implement only the scope of the assigned issue and its acceptance criteria.
- Do not change deployment permissions, GitHub workflows, or infrastructure unless explicitly authorized in the issue.
- Never commit secrets or credentials.
- Add or update automated tests for behavior changes.
- Run `npm test` and `npm run lint` before proposing a pull request.
- Do not bypass checks, push to main, merge, or deploy.
- If acceptance criteria are ambiguous, ask for clarification rather than inventing requirements.
